# Contributing to Nib

Thanks for helping! Bug reports and ideas are welcome as
[issues](https://github.com/pedda90/Nib/issues).

## Changes to the code
1. Fork the repository and make your change in your fork.
2. Open a pull request with a short description of what it changes and why.
3. The maintainer reviews it and merges it, asks for changes, or declines it.

Please test your change with the real plotter or at least with the built-in **SIMULATOR** port,
and keep the user interface and documentation in English.
